Cranford Historical AR — Xcode project

Release 0.2.0 (16) — Stop 1 public viewing point and Greystone AR fixes

1. Close the previous Xcode project. Extract the entire ZIP into a fresh folder on the Mac. Keep its folders together.
   Copy your existing Config/Secrets.xcconfig into this new folder’s Config folder.
2. Double-click CranfordHistoricalAR.xcodeproj inside this folder.
3. Allow Xcode to download package dependencies.
4. Connect and unlock your iPhone, and accept Trust if asked.
5. In Xcode select the blue project icon, then Targets > CranfordHistoricalAR > Signing & Capabilities.
6. Turn on Automatically manage signing and select your Apple account under Team.
7. Select your iPhone in the top toolbar. Choose Product > Clean Build Folder, then click Run.
8. On the iPhone open Home > Developer. Installed build and narration must show 0.2.0 (16), audio release cedar-2.
   After tapping Play, Prepared audio should say bundledAudio with stop_01 or stop_02, never synthesizedSpeech.

Homebrew and XcodeGen are not needed to open this generated project.
Xcode is still required. This project was generated on Linux; a successful iOS build and installation have NOT been verified.

Without Google API keys, the existing fallback map and estimated distances are expected.
Do not enter Google keys in the example file or commit them to GitHub. Use Config/Secrets.xcconfig if configuring real Maps/Routes.

New interface quick check:

- Tap the mill photo, pinch to zoom, then tap X. Return to the same stop.
- Play narration and switch tabs. Playback should continue.
- Open Stop details for the address, recording, photo and View in AR. Start AR targets the selected site; the Map AR button resumes the guided destination.
